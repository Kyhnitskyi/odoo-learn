===========
HR Hospital
===========

Модуль для автоматизації роботи лікарні: облік лікарів, пацієнтів,
захворювань та візитів.

.. contents:: Зміст
   :local:

Опис
====

**HR Hospital** дозволяє вести:

- картки лікарів із кваліфікаційною категорією, ментором та ознакою
  «інтерн»;
- картки пацієнтів із загальною медичною інформацією (стать, дата
  народження, вік, група крові);
- історію персональних лікарів пацієнта;
- ієрархічний довідник видів захворювань;
- облік візитів пацієнтів до лікарів із зазначенням діагнозу.

Модель ``hr.hospital.medic.info`` є абстрактною і надає спільні поля
(стать, дата народження, вік, група крові) моделям лікаря та пацієнта,
тому ці дані не дублюються.

Функціонал
==========

Лікарі та пацієнти
-------------------

- Спеціальність, кваліфікаційна категорія (``hr.hospital.doctor.category``)
  та зв'язок з користувачем системи (``res.users``) для лікаря.
- Ментор та інтерни: лікар може бути ментором для інших лікарів
  (поле ``mentor_id`` / обчислюване ``intern_names``).
- Персональний лікар пацієнта та повна історія його зміни
  (``hr.hospital.doctor.history``).

Захворювання
------------

Ієрархічний довідник ``hr.hospital.disease`` з батьківською категорією
(``parent_id``) — дозволяє групувати діагнози за типом захворювання.

Візити
------

Модель ``hr.hospital.visit`` реєструє візит пацієнта до лікаря з
обов'язковим зазначенням діагнозу. Завершені (заблоковані) візити
захищені від подальших змін.

Візарди
-------

- **Швидкий запис** (``quick.visit.wizard``) — швидка реєстрація
  візиту пацієнта до лікаря без переходів між екранами.
- **Масове перевизначення лікаря** (``mass.reassign.doctor.wizard``) —
  групова зміна персонального лікаря для кількох пацієнтів одразу.
- **Звіт по візитах** (``visit.report.wizard``) та **звіт по хворобах
  за місяць** (``disease.report.wizard``) — доступні через меню Друк
  у картці лікаря.

Представлення
--------------

Список, форма, календар, канбан, зведена таблиця (pivot), графік та
бічна панель пошуку (search panel) — для аналізу завантаженості
лікарів і статистики візитів.

Права доступу
=============

Модуль додає категорію прав «Лікарня» з ієрархією ролей, де кожна
наступна успадковує права попередньої:

#. **Пацієнт** — базовий доступ, бачить і працює лише з власними
   візитами.
#. **Інтерн** — успадковує права пацієнта; бачить і редагує візити,
   де сам є лікарем.
#. **Лікар** — успадковує права інтерна; додатково бачить і редагує
   візити своїх інтернів.
#. **Менеджер** — успадковує права лікаря; перегляд усіх візитів без
   права редагування.
#. **Адміністратор** — успадковує права менеджера; повний доступ,
   включно з видаленням лікарів, пацієнтів, захворювань та історії.

Встановлення
============

Модуль не має зовнішніх залежностей окрім ``base``. Для встановлення
достатньо стандартної процедури Odoo — через інтерфейс
«Налаштування → Застосунки» або з командного рядка::

    odoo-bin -c <config> -i hr_hospital --stop-after-init

Налаштування
============

Додаткове налаштування не потрібне. Довідники кваліфікацій лікарів та
видів захворювань постачаються разом з модулем (``data/``); демонстраційні
дані (лікарі, пацієнти, візити) доступні за потреби у режимі demo.

Використання
============

#. Створіть картки лікарів (з категорією та, за потреби, ментором) і
   пацієнтів.
#. Призначте пацієнту персонального лікаря — зміни фіксуються в
   історії персональних лікарів.
#. Реєструйте візити вручну або через візард швидкого запису.
#. Використовуйте меню Друк у картці лікаря для звітів по візитах та
   хворобах за обраний період.

HR Hospital

Комплексний облік лікарів, пацієнтів та візитів у лікарні

Модуль для автоматизації роботи лікарні: картки лікарів і пацієнтів, історія персональних лікарів, ієрархічний довідник захворювань, облік візитів та зручні візарди для щоденної роботи персоналу.

Лікарі та пацієнти

Картка лікаря

Спеціальність, кваліфікаційна категорія, ментор та ознака "інтерн", зв'язок з користувачем системи, список пацієнтів та історія візитів.

Картка пацієнта

Загальна медична інформація (стать, дата народження, вік, група крові), персональний лікар, історія зміни лікарів та список візитів.

Візити та захворювання

Облік візитів

Реєстрація візитів пацієнтів до лікарів із зазначенням діагнозу, контроль обов'язкових полів та захист заблокованих візитів від змін.

Довідник захворювань

Ієрархічна структура видів захворювань з можливістю групування за батьківською категорією.

Візарди для швидкої роботи

Швидкий запис

Швидкий запис пацієнта на прийом до лікаря без переходів між екранами.

Масове перевизначення

Масова зміна персонального лікаря для групи пацієнтів.

Звіти по місяцю

Звіт по візитах та звіт по хворобах за обраний період.

Гнучкі представлення даних

Список, форма, календар, канбан, зведена таблиця (pivot), графік та бічна панель пошуку (search panel) — для зручного аналізу завантаженості лікарів та статистики візитів.

Changelog
=========

19.0.1.1.0
----------

- Додано довідник кваліфікацій лікарів (категорії лікарів,
  ``hr.hospital.doctor.category``).
- Додано історію персональних лікарів пацієнтів
  (``hr.hospital.doctor.history``).
- Виділено абстрактну модель загальної медичної інформації
  ``hr.hospital.medic.info`` (група крові, стать, дата народження, вік).
- Додано категорію, ментора та ознаку «інтерн» для лікарів.
- Реалізовано ієрархічну структуру видів захворювань
  (``hr.hospital.disease``).
- Розширено поля та правила для візитів пацієнтів, включно з
  захистом заблокованих візитів від змін.
- Додано візард масового перевизначення персонального лікаря
  (``mass.reassign.doctor.wizard``).
- Додано візард звіту по візитах (``visit.report.wizard``).
- Додано нові представлення: calendar, pivot, graph, kanban,
  search panel.
- Додано візард швидкого запису пацієнта до лікаря
  (``quick.visit.wizard``).
- Додано візард звіту по хворобах за місяць
  (``disease.report.wizard``), доступний через меню Друк у картці
  лікаря.

19.0.1.0.0
----------

- Перший реліз модуля.
- Базовий облік лікарів (``hr.hospital.doctor``) та пацієнтів
  (``hr.hospital.patient``).
- Облік візитів пацієнтів до лікарів (``hr.hospital.visit``).
- Базові права доступу та групи модуля.
